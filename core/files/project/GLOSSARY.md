# Glossary

The words this project uses, in plain sentences. Add a term when a file needs one that is not here.

- **Owner:** {{OWNER}}, who decides what only they can decide; see [working-agreement.md](working-agreement.md).
- **Decider:** the person who owns a call in the decision table of [working-agreement.md](working-agreement.md).
- **Session:** one run of Claude Code. It remembers nothing from the last one except what the project files say.
- **Handoff note:** the note at the top of [plan.md](plan.md) that lets the next session carry on.
- **Default:** the answer used until {{OWNER}} gives a different one. No question waits without one.
- **Decision log:** the dated list in [decisions.md](decisions.md) of costly decisions. It is never rewritten.
- **Belief:** something the project rests on, written with the result that would prove it wrong.
- **Kill line:** a result, written before a test, that ends or changes the project when it fails.
- **Grade:** how well a plan item is backed: validated, bet or assumption.
- **Stage:** how far a claim has travelled: proposed, delivered, reported, measured or verified.
- **Recon:** quick fact-finding, such as reading files or searching, done by a cheap model.
- **Mode:** who accepts finished work: `solo`, `orchestrator`, `human-review` or `issues-only`; see [working-agreement.md](working-agreement.md).
- **Review:** a check by a fresh session, or a person, that did not write the change.
- **Hook:** a script Claude Code runs before or after a tool call; `guard.sh` stops or queries risky commands this way.
