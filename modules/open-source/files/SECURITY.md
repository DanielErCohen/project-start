## Report a vulnerability

Send the report privately. A public issue or pull request exposes users before a fix exists.

- Use the host's private vulnerability report (the Security tab of the repository), or
- write to the maintainer's security address.

> ADAPT: put the security address on the line above, or delete that option if the host's private report is the only channel.

Include what you found, the version, steps to reproduce and the impact you expect. Do not include other people's data.

## What to expect

- An acknowledgement within 3 working days.
- A first assessment within 10 working days, and a fix plan with a date when the report is valid.
- A credit in the release notes if you want one.

Please allow time for a fix before you share details. If a fix is not possible, we will tell you why.
