# Incident

Use this page when personal data may have been exposed, lost, altered or sent to the wrong person. Keep it printable, since nobody designs a process at hour two.

## The first hour

1. **Write down the time of awareness** with a time zone. Every legal clock starts there.
2. **Contain:** stop the exposure. Revoke the key, disable the endpoint, remove the public link, or ask the recipient of a misdirected message to delete it. Delete nothing of your own yet.
3. **Preserve evidence:** copy logs, request records, the sent message and affected configuration to a private place before changing them.
4. **Tell {{OWNER}}** the time of awareness, what is known and what is not.

## Then

5. Assess the categories (`privacy.md`), the number of people, and whether the data was exposed or taken.
6. Decide on notification with {{OWNER}} and a lawyer. The agent drafts any notice and sends nothing.
7. Fix the cause and add the check that would have caught it.

## A message sent to the wrong recipient

An email, file or chat message with a client's or user's data reached someone it was not for.

1. Do not send a second message to a group or reply-all. Write to the wrong recipient alone, asking them to delete it and to confirm in writing; recall the message if the system allows.
2. Record who got it, what it held, which person's data it was, and when it was sent and noticed.
3. Tell {{OWNER}} at once. {{OWNER}} decides whether the person whose data it was, the client or a regulator must hear of it, and checks the engagement letter or contract for duties.
4. Add the check that would have caught it: recipient confirmation before sending, or sending from a draft that {{OWNER}} reads.

## The notification clock

## One record per event

Every incident gets a record, including those where no notice is due, because the rules behind the 72-hour clock require it. Save it as `project/incidents/YYYY-MM-DD-topic.md` with: aware at, what happened, data and people affected, contained at and how, evidence location, notification decision (who, when), notices sent, cause and fix, check added.
